Append one entry to `JOURNAL.md` (never rewrite earlier entries). Use this format:

```
## YYYY-MM-DD · step <id> · <hours>h
- Did: <one line>
- Decision: <choice made and why, one line each>
- Rows: <counts before/after filters, if any>
- Result: <the number or sanity-test outcome>
- Next: <one line>
```

Ask me for the hours spent if you don't know them. $ARGUMENTS may contain extra notes to include.
